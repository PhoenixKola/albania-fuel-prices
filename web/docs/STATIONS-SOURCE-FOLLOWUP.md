# Stations source handoff

The website calls `https://fuel-proxy.fenixkola.workers.dev` for Albanian station searches. The repository does not contain the deployed Worker v5 source, its snapshot-generation pipeline, or the deployment configuration. Do not infer a new snapshot publication date from a successful HTTP request. The web label is maintained in `src/config/stationSnapshot.ts` and currently says 2026-10-20; verify the deployed snapshot before changing it.

To make updates reproducible, export and commit the Worker source and configuration, the exact OSM extraction inputs and license attribution, the generation commands and filters, the date/provenance metadata emitted by the Worker, and deployment steps. After each update, check `/health`, query a known Albanian location, verify node and way results, and update the web snapshot date only when the published data are confirmed. The web place picker uses a separate GeoNames AL extract (CC BY 4.0); run `node web/scripts/sync-station-places.mjs` from the repository root after regenerating the mobile source, then verify the `retrieved` date in `web/src/data/albaniaPlaces.json` and `web/src/config/stationSnapshot.ts`.

Outside Albania, the website uses public Overpass endpoints with bounded fallbacks. Their availability and CORS behavior are outside this repository's control. Reliable worldwide coverage would require an operated, monitored data service. Border-area enrichment is deferred until the maintained Worker source and snapshot geography can be inspected; the coarse Natural Earth boundary in the client is not a precise legal border.
