# Fuel data and deployment monitoring

The European table's `as_of` is the source's publication date. `fetched_at_utc` records when an accepted reading was downloaded; `build-date` and `build-sha` identify the Cloudflare Pages build. Fetching or rebuilding does not create a newer fuel publication.

`Update fuel data (Europe)` keeps Cargopedia first and logs any reason for using Tolls. `UNCHANGED` leaves all data files untouched and does not deploy. `SOURCE_DATE_CONFLICT` means values changed under the same publication date: the accepted files are quarantined, the scheduled job succeeds with a visible warning and one open review issue, and deployment is skipped. Review the provider's date label and value differences; do not advance `as_of` manually. `UPDATED` accepts a verified newer Europe publication, commits changed data and calls the existing reusable deployment workflow. `UPDATED_KOSOVO` changes only the independently dated Kosovo row in `latest.json`, retaining Europe's date and history. `FAILED` signals an unusable source, invalid dates or table, corrupt stored data, or an operational failure.

`Verify live site is fresh` compares the live publication date with accepted `data/latest.json` and checks that the deployed `build-sha` contains the latest changes to `web/`, `data/`, or the deployment workflow. A source older than three days is a warning if the site and repo agree. An older live publication or a missing web-relevant commit is a deployment failure. The first legacy build without `build-sha` is tolerated only when its build date covers the latest relevant commit; the marker becomes enforceable after the new deploy.

Cloudflare Pages project `karburanti-sot` is a **Direct Upload** project. `.github/workflows/deploy-web.yml` builds and uploads with `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`. There is no Pages Git integration or deploy hook to configure. Review the Deploy web run and the public homepage markers after any accepted data update. A GitHub issue titled “Fuel source publication-date discrepancy” stays open until a verified newer Europe publication is accepted; if Issues permissions are unavailable, use the ingest job summary and annotation.
